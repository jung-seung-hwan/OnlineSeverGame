## 작업 기록 (`work/`)

작업마다 문서 하나를 두고, 작업하면서 계속 갱신한다. 사람이 읽고 "무엇을 어떻게 만들었고 실제로 어떻게 플레이되는지"를 알 수 있게 쓴다. 각 세션은 자기 작업 문서와 이 표의 자기 행만 고친다.

| 작업 | 문서 | 담당 세션 | 상태 |
|---|---|---|---|
| 핵심 게임 서버 | [work/server-core.md](work/server-core.md) | 핵심 게임 서버 · 01 | 핵심 완료, 클라이언트 연동 확인, 다듬기 1차 완료 |
| Unity 클라이언트 | [work/unity-client.md](work/unity-client.md) | Unity 클라이언트 · 01 | 핵심 완료, 서버·봇과 라운드 확인. 다듬기 남음 |
| 캐릭터·맵 아트 | [work/art.md](work/art.md) | 캐릭터·맵 아트 · 01 | 레퍼런스·콘셉트 이미지 1차 완료, Blender 기준 이미지 선택 대기 |

### 작업 문서에 들어갈 것

1. **어떻게 플레이되는가**: 이 작업으로 바뀐 게임 경험(조작, 규칙, 화면에 보이는 것)
2. **어떻게 구현했는가**: 구조, 흐름, 핵심 결정과 이유, 코드 위치
3. **직접 돌려 보기**: 실행 명령과 무엇을 보면 되는지
4. **확인한 것과 남은 일**: 실제로 확인한 것과 확인 못 한 것을 구별
5. **변경 기록**: 날짜, 커밋, 한 줄 요약 (작업할 때마다 추가)
