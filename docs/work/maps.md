# 작업 기록: 다중 맵

- 담당 세션: `[OnlineSeverGame] 다중 맵 · 01`
- 상태: **단계 A(배치·위험물 설계) 확정.** 단계 B(구현)는 `[OnlineSeverGame] 조작·상호작용 추가 · 01`(작업 문서 `gameplay-2.md`)이 끝난 뒤 시작한다.
- 확정된 맵 테마(다시 정하지 않음): 주방(기존) + 겨울 처마(고드름, 얼음 발판) + 창고(화물 상자, 떨어진 상자는 밀 수 있는 발판) + 디저트 가게(포크, 녹아서 줄어드는 아이스크림 발판). 라운드마다 맵을 바꾼다.
- 이 문서의 좌표·크기는 **신규 맵 아트 세션이 그대로 렌더하는 기준**이다. 숫자를 바꾸면 이 문서를 먼저 고치고 변경 기록에 적는다.

단위는 `docs/protocol.md`와 같다. 좌표는 정수 밀리유닛(1유닛 = 1000), Y 위가 +, 바닥 윗면 y = 0, 플레이어 위치는 몸 아래 가운데. 표에는 편의상 유닛(소수)으로 적고, 코드에는 ×1000 한 값을 넣는다.

## 1. 어떻게 플레이되는가

### 공통 틀

- 네 맵 모두 **가로 24 × 세로 13.5 유닛** 화면(주방과 같음). 카메라·UI·아트 배율(맵 72 px/유닛)을 그대로 쓰고, 맵마다 다른 건 발판 배치·위험물·고유 규칙이다.
- 바닥(y = 0, x 0~24)은 항상 있고 단단하다. 양 끝은 벽. 발판은 기존처럼 한 방향(위에서만 착지, 아래에서 통과, 아래키+점프로 내려가기 — 조작 세션의 새 조작).
- 위험물은 맵마다 한 종류. 모두 **예고 → 낙하 → 착지** 순서이고 예고 기둥(위험물 폭, 꽂힐 면까지)을 그린다. 낙하 중인 위험물에 몸이 닿으면 즉사. 첫 위험물은 Playing 시작 1초 뒤.
- 오르기 기준(물리 상수 그대로): 점프 최고 2.8유닛 → **발판 사이 높이 차 2.4 이하면 점프로 오른다.** 3.2 이상은 점프+대시나 상자 같은 디딤이 필요하다.

### 맵 순서

- 기본은 **순환**: 주방(1) → 겨울 처마(2) → 창고(3) → 디저트 가게(4) → 주방(1) …. 서버를 켜면 첫 라운드는 주방.
- 맵은 **새 라운드 번호의 Countdown이 시작될 때** 바뀐다. 카운트다운 중 입장으로 같은 번호 RoundStart가 다시 가도 맵은 그대로. 카운트다운이 인원 부족으로 취소되면 다음 시도도 같은 맵(순환이 건너뛰지 않음).
- 대기(Waiting) 중에는 마지막으로 쓴 맵에 서 있다(서버 시작 직후는 주방).
- 서버 옵션(단계 B): `--maps cycle`(기본) / `--maps random` / `--map N`(한 맵 고정, 시험용). `random`은 4개 중 무작위이되 **직전 맵은 제외**(같은 맵 연속 금지). 시드 옵션 `--seed`를 따른다.
- 이유: 순환이면 네 맵을 고르게 보고, 봇 시험에서 "맵 4개가 차례로" 확인이 쉽다. 무작위는 플레이해 보고 원하면 옵션으로 켠다.

### 맵 한눈에

| id | 맵 | 위험물 | 고유 규칙 | 밀리는 오브젝트 | 숨을 곳의 성격 |
|---|---|---|---|---|---|
| 1 | 주방 (기존 `Stage.Default`) | 식칼 | 없음 | 조작 세션이 정함 | 발판 아래 넓음, 끝까지 그대로 |
| 2 | 겨울 처마 | 고드름 (처마에 매달려 흔들리다 가속 낙하) | 얼음 발판·얼음 웅덩이에서 미끄러짐. **고드름은 얼음 발판을 뚫는다** | 눈덩이 1 | 얼음 창턱 아래는 안전하지 않음, 나무 들보·벤치 아래만 안전 |
| 3 | 창고 | 화물 상자 (넓고 느림) | 떨어진 상자가 밀 수 있는 발판으로 남음(최대 6개, 2단까지) | 시작 상자 2 + 떨어진 상자 | 선반 랙 2층 구조, 상자가 쌓이며 지형이 바뀜 |
| 4 | 디저트 가게 | 포크 (칼보다 넓음) | 아이스크림 발판 4개가 10초 뒤부터 녹아 줄어듦 | 마카롱 1 | 처음엔 넓다가 점점 좁아짐 |

## 2. 맵별 배치 (확정 수치)

공통: 너비 `Width = 24000`, 카메라 높이 `ViewHeight = 13500`. 스폰 지점은 참가자 순서대로 쓰며 모두 바닥(y = 0). `R`은 오른쪽을 봄(facing +1), `L`은 왼쪽(−1).

### 2.1 주방 (id 1, 기존 그대로)

`Stage.Default` 그대로. 발판 x 3~9 / 15~21 윗면 2.4, x 9~15 윗면 4.8. 위험물 식칼, 시작 높이 14.0. 밀리는 오브젝트·흔들리는 장식은 조작 세션(`gameplay-2.md`)이 정한 것을 따른다. 이 작업에서 주방 배치는 바꾸지 않는다.

### 2.2 겨울 처마 (id 2)

밤, 눈 쌓인 집 벽 앞. 화면 맨 위에 지붕 처마가 가로로 걸쳐 있고 고드름이 처마 아래(y 13.0)에 매달린다.

```
 13.0 ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼  처마 (고드름 매달림)
  4.8              [===들보===]          [===들보===]
                  5.0       9.5        14.5       19.0
  2.4  [~~~얼음 창턱~~~]                         [~~~얼음 창턱~~~]
       1.5          6.5                         17.5         22.5
  1.6                         [==벤치==]
                              10      14
  0.0 ================[~~~~~~얼음 웅덩이~~~~~~]=================  눈 바닥
      0               8                       16              24
```

| 면 | 종류 | x 범위 (유닛) | 윗면 y | 밀리유닛 |
|---|---|---|---|---|
| 바닥 | 눈 (보통) | 0 ~ 24 | 0 | |
| 바닥 얼음 웅덩이 | **얼음** | 8.0 ~ 16.0 | 0 | 8000 ~ 16000 |
| 왼쪽 창턱 | **얼음** | 1.5 ~ 6.5 | 2.4 | 1500 ~ 6500, 2400 |
| 오른쪽 창턱 | **얼음** | 17.5 ~ 22.5 | 2.4 | 17500 ~ 22500, 2400 |
| 벤치 | 나무 (보통) | 10.0 ~ 14.0 | 1.6 | 10000 ~ 14000, 1600 |
| 왼쪽 들보 | 나무 (보통) | 5.0 ~ 9.5 | 4.8 | 5000 ~ 9500, 4800 |
| 오른쪽 들보 | 나무 (보통) | 14.5 ~ 19.0 | 4.8 | 14500 ~ 19000, 4800 |

- 오르는 길: 바닥 → 창턱(2.4) → 들보(4.8, 창턱과 x 5.0~6.5 / 17.5~19.0이 겹침). 바닥 → 벤치(1.6). 벤치에서 들보는 높이 차 3.2라 점프로는 안 되고 점프+대시로만.
- 스폰: x = 1.0 R, 23.0 L, 3.5 R, 20.5 L, 7.0 R, 17.0 L, 10.5 R, 13.5 L (10.5, 13.5는 얼음 웅덩이 위).
- 위험물 시작 높이(`HazardSpawnY`, 고드름 끝): **11.8** (고드름 길이 1.2, 윗끝이 처마 아랫면 13.0에 붙음).
- 고드름은 x = 0.5, 1.5, …, 23.5 (1유닛 간격 24자리) 중에서 고른다. 처마에 고드름이 줄지어 달린 모양.
- 안전지대(고드름이 얼음을 뚫으므로): 들보 아래 바닥·창턱(x 5.0~9.5, 14.5~19.0), 벤치 아래 바닥(x 10~14, 단 얼음이라 밀리면 미끄러져 나감). **창턱 아래 x 1.5~5.0, 19.0~22.5는 안전하지 않다.** 맨바닥 노출: x 0~5.0, 9.5~10, 14~14.5, 19.0~24.
- 8명이 설 자리: 바닥만으로 충분(24유닛), 안전지대 폭 합 13유닛 = 몸 0.8 기준 16명분.

### 2.3 창고 (id 3)

어두운 창고, 양쪽 벽에 2층 철제 선반 랙, 가운데 천장 크레인 레일에 사슬로 매단 팔레트.

```
  4.8  [=랙 위칸=]                                      [=랙 위칸=]
  3.6                      [====팔레트====]
  2.4  [=랙 아래칸=]                                    [=랙 아래칸=]
  1.2               [상자]                    [상자]           ← 시작 상자 2개
  0.0 ==========================================================  콘크리트 바닥
      0 1        5    7.3  8.7  9.5      14.5 15.3 16.7  19     23 24
```

| 면 | 종류 | x 범위 | 윗면 y | 밀리유닛 |
|---|---|---|---|---|
| 바닥 | 콘크리트 | 0 ~ 24 | 0 | |
| 왼쪽 랙 아래칸 | 철판 | 1.0 ~ 5.0 | 2.4 | 1000 ~ 5000, 2400 |
| 왼쪽 랙 위칸 | 철판 | 1.0 ~ 5.0 | 4.8 | 1000 ~ 5000, 4800 |
| 오른쪽 랙 아래칸 | 철판 | 19.0 ~ 23.0 | 2.4 | 19000 ~ 23000, 2400 |
| 오른쪽 랙 위칸 | 철판 | 19.0 ~ 23.0 | 4.8 | 19000 ~ 23000, 4800 |
| 매단 팔레트 | 나무 | 9.5 ~ 14.5 | 3.6 | 9500 ~ 14500, 3600 |

- 오르는 길: 바닥 → 랙 아래칸 → 랙 위칸(아래칸에서 점프하면 위칸을 아래에서 통과해 올라섬). 팔레트(3.6)는 바닥에서 직접 못 오른다: 상자(1.2) 위에서 점프, 또는 랙 아래칸 끝(x 5.0)에서 달리며 점프(x 9.8쯤 높이 3.7로 닿음, 빠듯함)·점프+대시.
- 시작 상자 2개(밀리는 오브젝트): 바닥 위 가운데 x **8.0**, **16.0** (각 x 7.3~8.7, 15.3~16.7, 윗면 1.2).
- 스폰: x = 1.5 R, 22.5 L, 4.0 R, 20.0 L, 6.0 R, 18.0 L, 10.5 R, 13.5 L.
- 위험물 시작 높이(상자 아랫면): **14.0**. 상자 x는 [0.7, 23.3]에서 무작위.
- 안전지대: 랙 아래 바닥·아래칸(x 1~5, 19~23, 위칸이 지붕), 팔레트 아래 바닥(x 9.5~14.5). 상자가 쌓이면 상자 아래는 없으므로(상자는 바닥에 붙음) 지붕이 늘지는 않는다. 위칸·팔레트 위에 선 사람은 노출.

### 2.4 디저트 가게 (id 4)

밤의 디저트 가게 진열대 앞. 아이스크림 덩어리 네 개가 발판이고, 라운드 10초째부터 양 끝이 녹아 가운데로 줄어든다.

```
  6.0                        [초코]                 ← 3.0 → 1.0
  3.6               [=======바닐라=======]          ← 7.0 → 2.0
  2.0   [==딸기==]                       [==민트==]  ← 5.0 → 1.6
  0.0 ===========================[마카롱]============  체크무늬 타일
      0 1.5     6.5   8.5        12       15.5 17.5   22.5 24
```

| 발판 | 가운데 x | 처음 폭 → 최소 폭 | 처음 x 범위 | 윗면 y | 한쪽 녹는 속도 |
|---|---|---|---|---|---|
| 딸기 | 4.0 | 5.0 → 1.6 | 1.5 ~ 6.5 | 2.0 | 2 밀리유닛/틱 (0.04 u/s) |
| 민트 | 20.0 | 5.0 → 1.6 | 17.5 ~ 22.5 | 2.0 | 2 /틱 |
| 바닐라 | 12.0 | 7.0 → 2.0 | 8.5 ~ 15.5 | 3.6 | 2 /틱 |
| 초코 | 12.0 | 3.0 → 1.0 | 10.5 ~ 13.5 | 6.0 | 3 /틱 (0.06 u/s, 맨 위라 조명에 더 빨리 녹음) |

- 오르는 길: 바닥 → 딸기·민트(2.0) → 바닐라(3.6, 높이 차 1.6, 가로 2유닛 틈은 달리며 점프) → 초코(6.0, 높이 차 2.4). 바닥에서 바닐라로 직접은 못 감(3.6 > 2.8).
- 마카롱(밀리는 오브젝트): 바닥 x **12.0** (11.5~12.5, 높이 0.7).
- 스폰: x = 1.0 R, 23.0 L, 3.5 R, 20.5 L, 7.5 R, 16.5 L, 10.5 R, 13.5 L.
- 위험물 시작 높이(포크 끝): **14.0**. x는 [0.25, 23.75]에서 무작위.
- 녹는 시점(라운드 시작부터): 초코 26.7초에 최소, 딸기·민트 52.5초, 바닐라 72.5초. 그 뒤로는 최소 폭 그대로.
- 안전지대: 처음엔 바닥 x 1.5~6.5, 8.5~15.5, 17.5~22.5(합 17유닛). 1분 뒤에는 딸기·민트 아래 1.6씩 + 바닐라 아래 3.0 = 6.2유닛, 73초 뒤부터는 1.6 + 1.6 + 2.0 = 5.2유닛(몸 6명분). 끝으로 갈수록 자리 싸움이 된다.

## 3. 위험물

### 3.1 종류와 수치

| kind | 이름 | 맵 | 판정 폭 × 높이 | 예고 | 낙하 | 착지 후 |
|---|---|---|---|---|---|---|
| 1 | 식칼 (기존) | 주방 | 0.4 × 1.0 | 20틱(1초) 빨간 기둥 | 등속 700/틱(14 u/s), 시작 14.0 | 처음 닿는 면에 꽂혀 10틱 뒤 사라짐 |
| 2 | 고드름 | 겨울 처마 | 0.4 × 1.2 | 25틱(1.25초): 처마 아래에 고드름이 나타나 떨림 + 기둥 | **가속**: 속도 0에서 매 틱 +70, 최대 1000. 시작 11.8 → 바닥까지 19틱 | **얼음 면은 뚫고**, 처음 닿는 얼음 아닌 면(나무·바닥)에서 부서져 6틱 뒤 사라짐 |
| 3 | 화물 상자 | 창고 | **1.4 × 1.2** | 25틱(1.25초): 폭 1.4 기둥 + 착지 자리 그림자 | 등속 600/틱(12 u/s), 시작 14.0 → 바닥까지 24틱 | 처음 닿는 면(발판·바닥·쉬는 상자 윗면)에 멈춰 **쉬는 상자**(밀리는 오브젝트)가 됨 → 3.3 |
| 4 | 포크 | 디저트 가게 | 0.5 × 1.2 | 20틱(1초) 빨간 기둥 | 등속 700/틱, 시작 14.0 | 처음 닿는 면(아이스크림 포함)에 꽂혀 10틱 뒤 사라짐 |

- 위치는 모두 아래쪽 가운데(칼끝·고드름 끝·상자 아랫면·포크 끝).
- 판정은 기존 칼과 같다: 낙하 중인 위험물이 **그 틱에 지나간 영역 전체**와 살아 있는 플레이어 몸 상자가 겹치면 사망(관통 없음). 예고·착지 상태는 무해. 엎드린 플레이어는 조작 세션이 정한 낮은 판정 상자로 맞는다.
- 착지 면은 그 틱의 발판 모양으로 계산한다(아이스크림이 줄어 있으면 줄어든 폭 기준). 예고 기둥도 매 프레임 다시 계산해 그린다.
- 예고 색: 네 종류 모두 **빨간 기둥**(아트 방향 "칼과 예고만 최고 대비" 유지). 종류별 차이는 기둥 폭과 기둥 위쪽 표시(고드름은 실제 고드름이 떨림, 상자는 넓은 그림자)로 준다.

### 3.2 빈도 곡선

기존 식칼 공식을 맵별 값으로 쓴다(`roundTick` = Playing 시작 후 틱).

- 간격(틱) = `max(IntervalMin, IntervalStart − roundTick / IntervalStepTicks)`
- 한 번에 개수 = `min(CountMax, 1 + roundTick / CountStepTicks)`

| 맵 | IntervalStart | IntervalMin | IntervalStepTicks | CountMax | CountStepTicks |
|---|---|---|---|---|---|
| 주방 (기존) | 30 | 4 | 100 (5초) | 4 | 600 (30초) |
| 겨울 처마 | 30 | 5 | 100 | 4 | 600 |
| 창고 | 40 | 10 | 60 (3초) | 2 | 900 (45초) |
| 디저트 가게 | 30 | 5 | 100 | 4 | 600 |

| 0초 | 0.67개/s · 0.8 u/s | 0.67 · 0.8 | 0.5 · 1.1 | 0.67 · 0.9 |
| 30초 | 1.67 · 2.0 | 1.67 · 2.0 | 0.67 · 1.5 | 1.67 · 2.2 |

- 겨울 처마·디저트는 안전지대가 주방보다 적거나 줄어들어서 최소 간격만 5틱으로 한 틱 늦췄다.
- 창고는 상자가 넓고(맞는 폭 2.2) 쌓여 지형이 되므로 개수 대신 간격으로 조인다. 90초 뒤 상한은 주방 90초 수준에서 멈춘다.
- 생존 동선: 예고(1~1.25초) 동안 걸어서 8~10유닛을 움직일 수 있어 맞는 폭(1.2~2.2)을 벗어나기에 충분하다. 모든 맵에 끝까지 남는 지붕(주방 발판, 겨울 들보·벤치, 창고 랙·팔레트, 디저트 최소 폭 아이스크림)이 있어, 지붕 아래에 있으면 위험물로는 죽지 않는다(밀치기·밟기만 위협). 따라서 빈도가 최대여도 4초 이상 버틸 자리가 항상 있다. 실제 판 길이는 단계 B에서 피하는 봇으로 잰다.

### 3.3 창고 상자 규칙

- 떨어지는 상자(하늘에서 오는 것)만 위험하다. 바닥·발판·쉬는 상자에 닿으면 그 자리에 **쉬는 상자**가 된다. 판정 1.4 × 1.2.
- 쉬는 상자의 윗면은 한 방향 발판(위에서 착지, 아래키+점프로 내려감). 옆면은 플레이어를 막지 않는다(발판과 같은 방식, 예측이 단순하고 상자 사이에 갇히지 않음). 조작 세션의 밀리는 오브젝트가 옆면 충돌을 갖도록 만들어졌다면 그쪽 규칙을 따른다.
- 밀기: 조작 세션의 "대시·충돌로 밀리는 오브젝트" 규칙을 따른다. 그 규칙에 값이 없으면 기본값: 대시 중인 플레이어와 겹치면 대시 방향으로 vx = 600, 매 틱 vx −= vx/4(약 2.4유닛 밀림), 벽·다른 상자에 닿으면 멈춤. 움직이는 상자(|vx| ≥ 300)가 플레이어와 겹치면 대시에 맞은 것과 같이 밀친다.
- 쌓기: 상자 위에 상자는 **2단까지**. 이미 2단인 상자 위에 떨어지면 착지하면서 부서져(무해) 사라진다.
- 개수: 쉬는 상자 **최대 6개**(시작 상자 2개 포함). 7번째가 쉬게 되면 가장 오래된 쉬는 상자가 20틱 깜빡인 뒤 사라진다(깜빡이는 동안도 발판).
- 받침이 사라지거나 밀려 나가면 위 상자는 아래로 떨어진다(중력 100/틱², 최대 1000). 이렇게 떨어지는 상자는 **무해**하고 처음 닿는 면에 다시 쉰다. 상자 위에 서 있던 플레이어도 받침이 사라지면 그냥 떨어진다.
- 라운드가 끝나면(Ended) 쉬는 상자를 모두 없애고, 다음 Countdown에서 시작 상자 2개를 다시 놓는다.

### 3.4 겨울 처마 얼음 규칙

- 얼음 면: 얼음 발판(창턱 2개) 위, 또는 바닥 얼음 웅덩이(x 8~16) 위에 섰을 때(바닥은 몸 가운데 x 기준).
- 얼음 위 걷기: 목표 속도(방향 × 이동 속도, 엎드리면 엎드린 속도)로 vx를 **매 틱 최대 50씩** 바꾼다. 0 → 8 u/s 0.4초, 손을 떼면 1.4유닛 미끄러진다. 공중에서는 기존대로 바로 반응.
- 얼음 위 대시: 대시 자체는 같다. 대시가 끝나는 틱에 vx를 ±400으로 줄인 뒤 위 규칙으로 미끄러진다(대시 뒤 1.4유닛 더 감).
- 얼음 위 밀치기: 얼음 면에 서 있다 맞으면 들려 올라가지 않고(vy 0) 미끄러진다. 스턴 동안 vx 감속 vx/8(보통 vx/4), 스턴이 끝나면 얼음 걷기 규칙으로 이어서 멈춘다. 약 5.0유닛 밀림(보통 약 2.4). 엎드려 있으면 조작 세션 규칙대로 넉백 절반.
- 고드름은 얼음 발판을 뚫는다(3.1). 바닥 웅덩이는 바닥이라 뚫지 않는다.

### 3.5 디저트 가게 녹는 규칙

- 아이스크림 발판의 반폭: `half(t) = max(MinHalf, StartHalf − max(0, roundTick − 200) × MeltPerTick)` (200틱 = 10초부터 녹음). 가운데 x는 고정, 양 끝이 같이 줄어든다.
- `roundTick`만으로 계산하므로 새 패킷 필드가 필요 없다(스냅샷의 roundTick으로 클라이언트가 같은 모양을 계산). 클라이언트 예측은 자기 예측 틱의 roundTick을 쓴다.
- Waiting·Countdown·Ended에는 roundTick이 0이므로 처음 폭이다(결과 화면에서 원래 크기로 돌아감).
- 줄어드는 끝에 서 있다 몸이 발판과 더는 가로로 겹치지 않으면 떨어진다(기존 착지 규칙 그대로).

## 6. 어떻게 구현할 것인가 (단계 B 계획)

조작 세션이 끝난 뒤 `gameplay-2.md`를 읽고 그 구조에 맞춰 조정한다. 지금 계획:

- `Shared/Simulation/Stage.cs`: `Stage.ById(1..4)`와 `Stage.All`. 발판에 면 종류(보통 / 얼음 / 녹음 + 녹는 값), 바닥 얼음 구간 목록, 맵별 위험물 종류·시작 높이·빈도 값·고드름 자리 목록, 조작 세션의 오브젝트 목록. `TryFindLanding`에 roundTick(녹는 발판)과 "얼음 무시"(고드름) 인자.
- `GameConstants` 또는 새 `HazardSpec`: 종류별 폭·높이·예고·낙하(등속/가속)·착지 틱.
- `Knife.cs` → 위험물 일반화(`HazardState`에 `Kind`). 이름은 바꾸되 식칼 동작은 그대로.
- `PlayerPhysics`: 얼음 가감속, 녹는 발판 착지. 클라이언트 예측도 같은 코드라 그대로 맞는다.
- 서버 `GameRoom`: 라운드마다 맵 교체(1절 '맵 순서' 규칙), 맵별 생성 곡선, 상자 → 쉬는 상자 변환·개수 상한·2단 제한, 얼음 밀치기.
- 프로토콜(버전 올림, `docs/protocol.md` 갱신): `RoundStart`에 `u8 stageId` 추가, 스냅샷 칼 항목에 `u8 kind` 추가(위험물 목록). 쉬는 상자는 조작 세션의 밀리는 오브젝트 목록으로 보낸다.
- 클라이언트: 맵별 그리기(아트 있으면 `Art/sprites/` 복사본, 없으면 단색 임시 도형), 위험물 종류별 그림·예고, 아이스크림 9-slice.
- 봇: 위험물 종류별 폭·낙하 시간·착지 면(고드름 얼음 관통, 녹는 발판)으로 피하기.
- 테스트: 맵 순환·무작위 연속 금지, 고드름 가속·얼음 관통, 얼음 미끄러짐 거리, 상자 착지·쌓기 2단·6개 상한·받침 사라짐, 아이스크림 폭 시간표, 포크 폭 판정.

## 7. 직접 돌려 보기

단계 B 이후에 적는다. 예정: `dotnet run --project Server/GameServer -- --exit-after-rounds 4` + 봇 8개로 맵 1→2→3→4 로그 확인, `--map N`으로 한 맵 반복.

## 8. 확인한 것과 남은 일

- 확인함(단계 A, 계산으로만): 발판 높이 차와 점프 높이(2.8)로 오르는 길, 맵별 안전지대 폭, 빈도 곡선 표, 고드름·상자 낙하 시간, 아이스크림 최소 폭 도달 시점, 아트 픽셀 크기(유닛 × 배율).
- 확인 안 함: 실제 플레이 손맛, 판 길이(봇으로 잴 예정), 얼음 미끄러짐·상자 밀기 값의 재미, 조작 세션 구조와의 맞춤(오브젝트 형식, 엎드리기 판정).
- 플레이 후 조정 후보: 창고 빈도, 얼음 가감속 50, 아이스크림 녹는 속도, 고드름 예고 25틱.
