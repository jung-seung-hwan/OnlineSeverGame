# 신규 맵 아트 (겨울 처마 · 창고 · 디저트 가게)

담당 세션: `[OnlineSeverGame] 신규 맵 아트 · 01`
범위: 새 맵 세 개의 콘셉트(Codex) → `docs/work/maps.md`(다중 맵 세션)의 좌표·크기·아트 목록대로 Blender 스프라이트를 렌더해 `Art/sprites/` 아래에 둔다. 클라이언트 연결은 다중 맵 세션이 한다.
기준: 아트 방향과 대비 규칙은 [art.md](art.md) 1장, 맵 테마는 사용자 확정(겨울 처마 = 고드름 낙하·얼음 발판 미끄러짐, 창고 = 화물 상자 낙하·떨어진 상자는 밀 수 있는 발판, 디저트 가게 = 포크 낙하·녹아서 줄어드는 아이스크림 발판). 다시 정하지 않는다.

## 1. 어떻게 보이게 되는가

세 맵 모두 주방 맵과 같은 틀이다: 손바닥만 한 젤리 눈높이에서 본 거대한 공간, 밤, 어둡고 저채도 배경, 발판·바닥 윗면에 밝은 선, 위쪽 절반은 위험물이 떨어지는 빈 공간, 발판 아래는 비어 있음(한 방향 발판). 빨간 반투명 기둥 + 착지 표시 + 위쪽 화살표 예고는 네 맵 공통이다.

| 맵 | 장소·조명 | 바닥 | 발판 | 위험물 | 맵 소품 |
|---|---|---|---|---|---|
| 겨울 처마 | 눈 덮인 나무집 처마 밑, 푸른 밤 + 서리 낀 창의 주황 불빛, 성긴 눈 | 눈 쌓인 나무 툇마루 | 얼음 덮인 판자 선반, 홈통에 사슬로 매단 얼어붙은 간판 | 고드름(끝이 아래, 반투명 흰 얼음) | 미끄러운 얼음 발판 |
| 창고 | 높은 창의 차가운 달빛 줄기 + 매달린 등 하나, 흐린 세로 랙과 상자 더미 | 나무 팔레트 | 칠 벗겨진 주황 강철 보, 호이스트 갈고리에 매단 팔레트 | 나무 화물 상자(정사각형) | 떨어진 상자 = 밀 수 있는 발판 |
| 디저트 가게 | 문 닫은 가게, 어두운 파스텔 줄무늬 벽, 진열장, 마카롱 탑, 펜던트 등 | 민트 타일 카운터 | 초콜릿 받침 위 웨하스, 리본으로 매단 바닐라·민트 아이스크림 | 은색 디저트 포크(갈래가 아래) | 녹아서 줄어드는 아이스크림 발판 |

발판 개수·위치·어느 발판이 얼음/아이스크림인지는 `maps.md`가 정한다. 위 표의 발판 해석은 콘셉트에서 쓴 것이고, 스프라이트(4.4)는 maps.md 배치를 따른다: 겨울 = 얼음 창턱 2 + 벤치 + 들보 2 + 바닥 얼음 웅덩이, 창고 = 2층 랙 2동 + 매단 팔레트 + 콘크리트 바닥, 디저트 = 아이스크림 4개(딸기·민트·바닐라·초코) + 체크무늬 타일 바닥.

## 2. 어떻게 만들었는가 (콘셉트)

규칙 2(기준 프롬프트)에 따라 기존 기준을 그대로 쓰고 맵 입력만 바꿨다. 기준 프롬프트는 개인 파일 `.vibe-local/prompts/`(Git 제외)에 있다.

- 배경 3장: `map-kitchen_v2` 브리프를 그대로 두고 장소·바닥·발판 재질·원경 소품·조명만 교체 → `map-winter-eaves_v1`, `map-warehouse_v1`, `map-dessert-shop_v1`. 구도 수치(바닥 8%, 낮은 발판 26%, 높은 발판 44%, 가로 12.5~37.5% 등)는 주방 `Stage.Default` 비율 그대로다. 생성 시점에 `maps.md`가 없었고, 콘셉트는 재질·조명·소품 참고용이며 배치는 Blender에서 좌표로 맞추기 때문이다(주방 맵과 같은 방식, progress 확정 사항 4).
- 위험물·소품 시트 3장: `knife-warning_v1`의 '바꿀 수 있는 입력'인 위험물 종류를 고드름·상자·포크로 교체. 맵 하나를 시트 한 장으로 보이려고 **네 번째 칸(맵 소품)을 추가**했다(ICE / PUSH / MELT). 구조가 바뀌어 새 파일로 저장했다(`hazard-icicle_v1`, `hazard-crate_v1`, `hazard-fork_v1`).
- 공통 고정 블록은 style_v2(현재 캐릭터 비율). 크기 비교용 캐릭터는 주방과 같은 2번(파랑 + 흰 리본).
- 실행: `bash build.sh <파일> style_v2.md > x.txt` → `codex exec --skip-git-repo-check -C D:/OnlineSeverGame - < x.txt`, 6장 병렬. 각 1장씩 한 번만 생성했다.

### 4.2 맵 폴더의 `map.json`

주방 `Art/sprites/map/map.json` 형식을 그대로 쓰고 `sprites`만 더한다.

```json
{
  "ppu": 72,
  "pieces": {
    "winter_bg.png":       { "world_rect": [-1.5, -1.5, 25.5, 14.0] },
    "winter_ice_sill.png": { "world_rect": [1.25, 1.525, 6.75, 2.525],
                             "instances": [[1.25, 1.525, 6.75, 2.525], [17.25, 1.525, 22.75, 2.525]] },
    "icecream_vanilla.png": { "world_rect": [8.25, 2.6, 15.75, 3.85],
                              "nine_slice": { "left_px": 54, "right_px": 54 }, "top_from_image_top_px": 18 }
  },
  "sprites": {
    "icicle.png": { "ppu": 128, "size": [64, 176], "pivot_px_from_bottom_left": [32, 8],
                    "pivot_normalized": [0.5, 0.04545], "note": "pivot = icicle tip" }
  }
}
```

- `pieces`: 72 px/유닛 정지 그림. 그림 왼쪽 아래를 `world_rect`의 (x0, y0)에 놓는다. `instances`가 있으면 같은 그림을 그 사각형들에 모두 놓는다(뒤집지 않음). 아이스크림은 `nine_slice`(양 끝 54 px 고정, 가운데만 늘이고 줄임)와 윗면 위치(그림 위에서 18 px 아래)를 함께 적는다.
- `sprites`: 128 px/유닛 움직이는 그림. `pivot_px_from_bottom_left`(px, 그림 왼쪽 아래 기준)와 `pivot_normalized`(Unity 피벗 값). 위험물은 아래 가운데(끝·아랫면), 밀리는 오브젝트는 아래 가운데, 흔들리는 장식은 매달린 점(위). 흔들 때 이 점을 축으로 돌린다.
- 그리는 순서(뒤 → 앞): bg → 흔들리는 장식 → 발판·바닥 → 밀리는 오브젝트·쉬는 상자 → 캐릭터 → 위험물·예고 → winter_eave(겨울만, 매달린 고드름 윗끝을 가림).
- 위험물 그림은 예고(겨울 고드름은 처마 아래 매달림)·낙하·착지 모두 같은 그림. 착지 후 효과는 `icicle_shards`(6틱), `crate_cracked`(사라지기 전 20틱).

- **창고**: 골함석 벽, 높은 창 두 개(달) 아래로 비스듬한 찬 빛줄기, 가운데 벽등 하나의 따뜻한 빛, 세로 H빔 기둥 두 개, 화면 양 끝 밖에 어두운 상자 더미. 맨 위 크레인 레일, 레일에서 팔레트까지 사슬 두 줄. 랙은 가는 기둥 + 주황 선반 보 두 칸, 팔레트는 중간 밝기 나무. 바닥은 콘크리트 + 노랑·검정 안전선. 상자는 밝은 소나무 + 짙은 외곽선이라 팔레트·바닥과 구별된다.
- **디저트 가게**: 어두운 파스텔 세로 줄무늬 벽, 왼쪽 창(가로등), 오른쪽 칠판 메뉴판(글자 대신 선), 마카롱 탑과 케이크 돔 실루엣, 위쪽 몰딩. 아이스크림 4개는 웨하스 받침 위의 둥근 끝 덩어리, 양 끝에서만 녹아 흐름. 바닥은 민트 체크무늬 타일.
- 위험물(고드름·포크)과 빨간 예고가 화면에서 가장 밝고 대비가 크다. 상자는 떨어질 때 예고 기둥이 위험을 알리고, 떨어진 뒤에는 윗면 밝은 선이 있는 발판으로 보인다.

확인한 것:
- 모든 그림의 픽셀 크기가 maps.md 5장 표와 같다(스크립트 REPORT로 확인, 예: winter_ice_sill 396 × 72, warehouse_rack 324 × 355, icecream_vanilla 540 × 90, crate 192 × 168).
