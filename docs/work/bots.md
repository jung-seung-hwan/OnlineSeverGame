# 혼자 하기와 서버 봇 (프로토콜 v14)

담당: 스토어 출시 준비 세션 · 브랜치 `claude/store-release-915848`

## 1. 무엇이 바뀌었나 (플레이)

- **혼자 하기**: 접속 화면에 있던 '오프라인 미리보기' 대신 **혼자 하기** 버튼이 생겼다. 누르면 이 PC 안에서 진짜 게임 서버가 뜨고 봇 7명과 한 방에 들어간다. 대기실에서 '시작'을 누르면 라운드가 시작된다.
  - 예전 미리보기는 서버 없이 흉내만 내는 화면이었다. 그래서 대시에 맞아도 납작 기절이 없었고, 밟기·옆 위험물·맵 이벤트·상자·점프 발판도 없었다. 사용자가 본 "오프라인에서 기절이 제대로 안 된다"의 원인이 이것이다.
  - 이제는 온라인과 같은 서버 코드(`Shared/Server`)가 돌기 때문에 기절·면역 깜빡임·밟기·옆 칼·맵 4개 순환이 모두 온라인과 똑같다.
- **난이도**: 혼자 하기 버튼 아래에서 고른다. 고른 값은 다음 실행에도 남는다(PlayerPrefs `botLevel`).

  | 난이도 | 경고를 알아채는 시간 | 아예 못 보는 위험물 | 피할 때 대시 | 사람 밀치기 | 옆 위험물이 날아올 때 |
  |---|---|---|---|---|---|
  | 쉬움 | 0.6~0.9초(경고 1초 중) | 35% | 안 씀 | 안 함 | 막 뛰고 대시함 |
  | 보통 | 0.15~0.35초 | 10% | 씀 | 가끔(가까우면 틱당 6%) | 점프·대시를 참음 |
  | 어려움 | 0.05~0.1초 | 0% | 씀 | 자주: 가까운 사람에게 걸어가서 대시(틱당 35%) | 점프·대시를 참음 |

  봇끼리는 거의 밀치지 않는다(어려움 3%, 보통 1%). 어려움이 '봇끼리 싸우다 같이 죽는 방'이 되지 않고 사람에게 어렵게 하려는 것이다.
- **방장이 봇 넣기**: '방 만들기'로 연 방(친구 초대 방)에서도 방장은 대기실 왼쪽 접속자 목록 아래에서 **− 봇 / + 봇** 버튼으로 봇을 넣고 빼고, **쉬움·보통·어려움**으로 난이도를 바꾼다. 혼자 하기 방도 같은 버튼으로 봇 수를 줄이거나 늘릴 수 있다.
  - 다른 사람 화면에는 "봇 N명 · 난이도 보통" 한 줄로 보인다. 접속자 카드에 회색 **봇** 표시가 붙는다.
  - 8명이 꽉 찬 방에 친구가 들어오면 가장 나중에 넣은 봇이 자리를 비켜 준다.
  - 봇은 방장이 될 수 없고, 사람이 아무도 없으면 라운드를 시작하지 않는다.
- 혼자 하기 방은 127.0.0.1에서만 열린다. 친구가 들어올 수 없으므로 대기실에 주소 칸이 없고, 공유기 포트(UPnP)도 열지 않는다.

## 2. 어떻게 만들었나

- **봇은 서버 안에 있다** (`Shared/Server/ServerBot.cs`).
  - 소켓 없이 `GameRoom`의 플레이어(`RoomPlayer.Bot`)로 들어간다.
  - 방은 매 틱 물리 스텝 전에 봇마다 틱 시작 시점의 상태(플레이어, 떨어지는 위험물, 옆 위험물, 상자, 이번 틱의 맵 모양)를 보고 입력 하나를 정한다. 그 입력은 사람 입력과 같은 큐(`QueueInput`)에 넣는다.
  - 그래서 판정·기절·관전·결과가 사람과 한 줄도 다르지 않다.
  - 콘솔 봇(`Tools/BotClient`)이 쓰던 회피 두뇌 `DodgeBrain`을 `Shared/Server/DodgeBrain.cs`로 옮겨(C# 9, 블록 namespace) 두 곳이 같이 쓴다.
- **난이도**는 반응 시간, 위험물 놓치기, 회피 대시, 사람 밀치기로 만든다.
  - 위험물 놓치기는 봇마다 정한 소금값과 위험물 id의 해시로 정한다. 그래서 틱마다 보였다 안 보였다 하지 않는다.
  - 반응 시간은 라운드마다 범위 안에서 다시 뽑는다.
  - 처음 만든 판에서는 어려움 봇이 서로 밀치다 같이 죽어서 쉬움보다 생존이 짧았다(쉬움 758틱, 어려움 678틱). 그래서 사람을 먼저 노리게 바꿨다.
  - 테스트로 재 보니 죽음의 절반이 옆 위험물이었다. 그래서 보통·어려움은 옆 위험물이 날아오는 동안 무작위 점프·대시를 참게 했다.
- **프로토콜 v14**.
  - `BotRequest`(54)가 추가됐다. 방장만 보낼 수 있고 action은 넣기·빼기·난이도 바꾸기다.
  - `RoomInfo` 끝에 `botLevel`과 `botMask`(봇인 플레이어 비트)가 붙었다.
  - 클라이언트는 `botMask`로 봇 표시를 하고, `botLevel`로 버튼 선택을 그린다.
- **혼자 하기 서버**: `LocalHost.Start(..., offline: true, botLevel)`로 연다.
  - 설정은 `ServerOptions { LoopbackOnly, Port = 0(빈 포트 아무거나), Bots = 7, BotLevel, BotNamePrefix = Loc "봇"/"Bot" }`이다.
  - 연 뒤 실제 포트(`GameServer.Port`)로 `NetworkSession`이 붙는다. 7777을 다른 프로그램이 쓰고 있어도 혼자 하기는 된다.
- 예전 `PreviewSession`은 `-preview` 인자로만 남겼다(UI 작업용, 판정 흉내).

## 3. 실행 방법

- 게임: 접속 화면에서 난이도를 고르고 **혼자 하기**를 누른 뒤, 대기실에서 **시작**을 누른다.
- 명령줄로 바로 혼자 하기:

```
Client/Build/Windows/Client.exe -offline hard
```

- 콘솔 서버에 봇 넣기: `dotnet run --project Server/GameServer -- --port 7777 --min-players 1 --bots 5 --bot-level hard`.
  - 사람이 한 명 들어와야 라운드가 시작된다.
- 테스트: `dotnet test --filter ServerBotTests`.

## 4. 확인한 것 / 못 한 것

- 확인함 (`Server/GameServer.Tests/ServerBotTests.cs`, 전체 305개 통과):
  - 봇 이름과 `botMask`, 봇은 방장이 아님, 봇에게는 패킷을 만들지 않음.
  - 봇만 있으면 라운드가 시작되지 않음.
  - 방장만 넣기·빼기·난이도를 바꿀 수 있음.
  - 꽉 찬 방에 사람이 들어오면 봇이 비켜 줌.
  - 봇이 대기실에서 움직이고, 시작 뒤 라운드 두 판을 끝까지 함.
  - 어려움 봇이 옆에 선 사람을 대시로 밀쳐 납작 기절시킴(`RoundDashStuns > 0`).
  - 난이도별 평균 생존(씨앗 3개 × 2판, 봇 7명): 쉬움 588틱(29초), 보통 801틱(40초), 어려움 1000틱(50초).
  - `BotRequest`·`RoomInfo` 왕복.
  - 혼자 하기 서버(127.0.0.1, 빈 포트, 봇 7명)에 TCP로 붙으면 8명이 보이고 `botLevel`이 맞음.
- 같이 고친 것: `PlayerHostTests.GameServer_HostStartsOverTcp`는 전체 테스트를 돌릴 때 손님의 Hello가 먼저 도착해 손님이 방장이 되는 경우가 있었다. 방장 접속 뒤 0.2초 기다리게 했다(테스트만 바꿈).
- 클라이언트(Unity 빌드)에서 확인함:
  - 접속 화면: '혼자 하기' 버튼과 쉬움·보통·어려움 버튼(고른 것이 노란색).
  - `-offline hard`로 한 판 해 봄. 봇이 대시에 맞아 납작 기절(별)하는 화면이 보이고, 서버 로그에 옆 칼·화구 불 죽음이 온라인과 같이 찍힘.
  - 혼자 하기 대기실: 접속자 8명(봇 7 + 나, 회색 '봇' 표시), "혼자 하기 · 봇 7명 · 난이도 쉬움", 주소 칸 없음.
  - 1280×720 영어에서는 처음에 8명 목록 때문에 캐릭터 고르기가 잘렸다. 그래서 6명 이상이면 카드를 낮게(37px) 그리게 고쳤고, 고친 뒤에는 다 보인다.
  - 한 PC 끝까지 시험(`artifacts/bots/run.ps1`): 방장 `-uitest -port 7808`, 손님 클라이언트, 콘솔 봇 2개. 자동 클릭 시험 **48개 모두 통과**(봇 넣기 2번 → 어려움 → 빼기 → 보통, 라운드, 결과, 혼자 하기에서 쉬움 → 봇 7명·방장 → 시작 → 나가기).
  - 손님 화면에도 서버 봇이 같이 뛰고, 손님 로그에 `bots 0x02 Normal`이 찍힘.
  - 클라이언트 로그에 예외 없음.
- 못 한 것: 사람이 직접 오래 해 보며 난이도가 알맞은지는 보지 않았다(숫자는 위 테스트뿐).
- 못 한 것: Store에 올라간 1.0.1.0 패키지는 v13이다. 이 변경을 내려면 패키지를 새로 만들어(버전 1.0.2.0) 다시 제출해야 한다. v13 게임과 v14 게임은 서로 접속할 수 없다(버전 불일치로 거절).
