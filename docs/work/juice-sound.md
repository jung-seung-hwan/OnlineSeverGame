# 타격감·사운드 (juice-sound)

담당 세션: `[OnlineSeverGame] 타격감·사운드 · 01` · 브랜치 `claude/juice-sound-d7d11d` (워크트리 `.claude/worktrees/juice-sound-d7d11d`)

목표: 서버·프로토콜은 그대로 두고 클라이언트만으로 손맛과 피드백을 올린다. 효과음·맵별 배경음·음량 설정, 파티클, 대시 충돌 멈춤, 근처 위험물 화면 흔들림, 늘어남·찌그러짐 강화, 마지막 두 명 카메라와 마지막 사망 슬로모션.

## 0. 소리 기준 (규칙 2: 만들기 전에 먼저 정한 기준)

모든 소리는 **직접 생성**한다(`Client/SoundGen/gen_sounds.py`, Python + numpy, 고정 시드). 외부 라이브러리 소리는 쓰지 않는다. 그래서 라이선스·출처 표기 조건이 따로 없다(9장 목록). 소리를 고칠 때는 아래 기준을 지키고 스크립트의 해당 함수의 입력(음높이·길이·필터)만 바꾼다. 기준 자체를 바꾸면 이 장에 버전과 이유를 적는다.

기준 v1 (2026-11-10)

| 항목 | 기준 |
|---|---|
| 공통 음색 | 젤리답게 **말랑하고 둥근 소리**. 사인·삼각파 위주, 날카로운 고음은 로우패스(대부분 4~7 kHz 아래)로 깎는다. 몸에서 나는 소리(점프·착지·대시·밟기·엎드림·터짐)에는 공통으로 **'출렁임'**(8~14 Hz 음높이·음량 떨림)과 음높이 미끄러짐(뾰잉·퐁)을 넣어 같은 생물의 소리로 들리게 한다. |
| 위험물 소리 | 판정이 걸린 정보라 몸 소리보다 또렷하게(대비 높게). 그래도 귀를 찌르지 않게 금속 울림은 짧게(0.3초 안), 고음 부분 음량은 낮게. 맵마다 재질이 다르다: 칼·포크 = 금속 '톡+챙', 고드름 = 유리 '짤랑', 상자 = 나무 '쿵'. |
| 길이 | 자주 나는 동작음(점프·착지·엎드림·대시) 0.06~0.2초. 충돌·밟기 0.2~0.35초. 터짐 0.45초 안팎. 예고음 0.2~0.3초. 징글(승리·패배) 1.2~2초. 8명이 같이 내도 겹쳐 쌓이지 않게 짧게. |
| 음량(파일) | 효과음은 피크 −3 dBFS로 맞추고, 실행 중 종류별 기본 음량(아래)으로 섞는다. 배경음은 피크 −6 dBFS로 만들고 기본 음량 0.45로 효과음 뒤에 깔리게 한다. |
| 실행 중 섞기 | 내 캐릭터 소리 1.0, 남의 소리 0.45(내 소리가 항상 앞에). 남의 소리는 화면 위치로 좌우를 조금 나눈다(±0.6). 동시 재생 최대 14개, 같은 소리 동시 3개·0.05초 안 재생 금지, 자리가 없으면 남의 오래된 소리부터 끊는다. 위험물 예고·꽂힘은 내 캐릭터와 가까울수록 크게(먼 것은 0.25배까지). |
| 배경음 | 맵마다 1곡, 끊김 없이 반복. 템포 96~120, 밝고 장난스러운 장조 위주(겨울 처마만 단조 섞기). 악기도 말랑한 쪽: 마림바·첼레스타·뮤직박스·부드러운 베이스·나무 타악기. 효과음이 들어갈 자리를 위해 2~5 kHz를 비우고 멜로디는 듬성듬성. 맵을 바꾸면 1초 동안 겹쳐 바꾼다. |
| 형식 | WAV 16비트 모노. 효과음 44.1 kHz, 배경음 22.05 kHz(저장소 크기와 말랑한 음색 둘 다를 위해). Unity 가져오기: 효과음 압축 없음·로드 시 풀기, 배경음 Vorbis 압축·메모리에 압축 유지. |

## 1. 어떻게 플레이되는가

소리(모두 직접 생성, 9장)

| 언제 | 소리 | 느낌 |
|---|---|---|
| 점프 | `sfx_jump` | 위로 올라가는 '뾰잉' |
| 착지 | `sfx_land` | 낮은 '퐁'. 높이서 떨어질수록 크게 |
| 대시 | `sfx_dash` | 짧은 '휙' |
| 대시에 부딪힘 | `sfx_dash_hit` | '퍽' + 출렁이는 '부웅' |
| 남의 머리를 밟고 튕김 | `sfx_stomp` | 스프링 '보잉' |
| 엎드리기 | `sfx_crouch` | 말랑한 '꾹'(같은 사람은 0.15초에 한 번) |
| 납작 기절 시작 | `sfx_stun` | 빙글빙글 내려가는 방울 소리 |
| 기절 면역 시작(깜빡임) | `sfx_immune` | 올라가는 작은 반짝임 |
| 위에서 떨어질 위험물 예고 | `sfx_warn` | 마림바 '띠링' 두 음(G5→C6). 내 캐릭터와 가로로 가까울수록 크다 |
| 위험물이 꽂힘 | `sfx_land_knife`(주방 칼) `sfx_land_icicle`(겨울 고드름) `sfx_land_crate`(창고 상자) `sfx_land_fork`(디저트 포크) | 맵마다 재질 소리. 가까울수록 크다 |
| 옆 위험물 예고 | `sfx_side_warn` | 올라가는 나무 블록 '똑똑똑'. 내 키 높이 줄이면 크다 |
| 옆 위험물이 내 곁을 지나감 | `sfx_side_pass` | 다가왔다 멀어지는 '휘융', 날아가는 쪽으로 소리가 옮겨 간다 |
| 젤리가 터짐(사망) | `sfx_death` | '뽁' + 질척한 '철퍽' + 방울 튀는 소리 |
| 카운트다운 3·2·1 / 시작 | `sfx_count` / `sfx_go` | 삑 / 밝은 화음 |
| 라운드 승리 / 패배 | `sfx_win` / `sfx_lose` | 마림바 올림 징글 / 장난스러운 '와와와와~'. 나는 동안 배경음이 낮아진다 |
| UI 클릭 | `sfx_click` | 짧은 '톡'(모든 젤리 버튼, UiHooks.ButtonClicked) |
| 배경음 | `bgm_kitchen` `bgm_winter` `bgm_warehouse` `bgm_dessert` | 맵마다 한 곡, 반복. 맵이 바뀌면 1초 겹쳐 바꿈. 접속 화면은 주방 곡 |

- 소리마다 '들리는 크기'를 맞췄다(기준 v2): 자주 나는 몸 소리는 작게, 위험물 예고·꽂힘은 몸 소리보다 3~5 dB 크게. 높은 '삐' 소리가 튀지 않는다.
- 내 캐릭터 소리는 크게, 남의 소리는 0.4배 + 고음을 깎아(4.5 kHz) 멀게 들린다. 화면 위치에 따라 좌우로 나뉜다. 위험물 소리는 내 캐릭터 근처일수록 크다.
- 시끄럽지 않게: 동시에 14개까지, 같은 소리는 동시 3개, 같은 소리를 내 것은 0.045초·남의 것은 0.08초 안에 다시 안 냄. 한 프레임에 같은 소리가 여러 번 생기면(칼 4개가 같이 꽂힘 등) 가장 큰 것 하나만. 자리가 없어 끊는 소리는 0.03초 동안 줄여서 끈다('딱' 소리 없음).
- **설정 창(Esc 또는 '설정' 버튼)의 '소리' 칸**: 효과음·배경음 음량 슬라이더, '화면 흔들림: 켜짐/꺼짐' 버튼. 바로 적용되고 다음 실행에도 기억한다. 모든 젤리 버튼을 누르면 '톡'.
- 배경음(기준 v2): 맵마다 손으로 쓴 선율·화음의 스테레오 곡. 주방 = 통통 튀는 마림바(C장조 112), 겨울 처마 = 첼레스타·하프·패드·썰매 방울(A단조 92), 창고 = 스윙하는 뜯는 줄·전자 피아노·나무 블록·금속 '쨍'(D 도리안 100), 디저트 가게 = 뮤직박스 왈츠(F장조 3/4 132, 두 번째에 글로켄·마림바 대선율).

파티클과 연출

- 착지(세게 떨어질수록 많이)·점프·대시(뒤쪽으로) 먼지.
- 위험물이 꽂힐 때 재질 색 파편(칼 은색, 고드름 하늘색, 상자 갈색, 포크 흰색)이 튀었다가 바닥에서 튄다 + 먼지.
- 젤리가 터질 때 그 젤리 색 방울이 튀고 바닥에 철퍽 퍼지며, 같은 색의 옅은 고리가 퍼진다.
- 밟기: 발밑에 흰 고리 + 작은 별. 대시 충돌: 두 캐릭터 사이에 더 큰 고리 + 별.
- 납작 기절 동안 머리 위를 노란 별 세 개가 돈다(뒤로 돌 때 캐릭터 뒤로). 기절 면역 동안 작은 반짝임이 올라온다.
- 대시 충돌 순간 화면 전체가 **0.05초 멈춘다**(0.3초 안에 다시 멈추지 않음). 화면 표시만 멈추고 조작·예측은 그대로라, 멈춘 만큼 0.04초 남짓 동안 빠르게 따라잡는다.
- 내 근처(가로 2.4·세로 2.5 안)에 위험물이 꽂히면 화면이 약하게 흔들린다(상자는 조금 더). 내가 대시에 맞거나 때려도, 내가 죽어도 흔들린다. 설정에서 끌 수 있다.
- 늘어남·찌그러짐 강화: 점프 순간 세로로 쭉, 착지하면 떨어진 속도만큼 납작해졌다가 스프링처럼 2~3번 출렁이며 돌아온다. 공중에서 빠를수록 살짝 늘어나고, 대시 시작에는 가로로 늘어난다(발밑 기준이라 발은 그대로).

마지막 두 명

- 라운드 참가자가 셋 이상이었고 생존자가 둘이 되면 카메라가 0.9배로 천천히 당겨지며 두 사람 사이를 본다(원래 화면 밖은 보이지 않게).
- 라운드를 끝내는 마지막 사망 순간: 화면이 0.25배 속도로 0.9초 흐르고(캐릭터 동작·파티클·장식 모두), 카메라가 0.84배로 사망 자리를 당겨 보고, 방울도 더 크게 터진다. 그동안 배경음이 조금 낮은 음으로 내려가고, 결과 패널과 승리·패배 징글은 슬로모션이 끝나고 따라잡은 뒤(약 1.3초 뒤) 나온다.

## 2. 어떻게 구현했는가

원칙: **서버·프로토콜·Shared 는 그대로**. 모든 사건은 클라이언트가 이미 그리는 상태(`WorldRender`, `SessionState`)의 프레임 사이 변화에서 찾는다. 새 패킷이 필요 없었다.

새 파일 `Client/Assets/Scripts/Juice/`

| 파일 | 하는 일 |
|---|---|
| `JuiceDirector.cs` | 총괄. 사건 찾기 규칙(보여 주는 `PlayerRender` 의 지난 프레임 q → 이번 p)

| 사건 | 조건 | 이유 |
|---|---|---|
| 점프 | q 땅 → p 공중, 위로 5 u/s 넘게, 기절 아님 | 대시에 맞아 뜨는 것(기절)과 구별 |
| 밟고 튕김 | 둘 다 공중, q 세로 속도 ≤ 1 → p > 8, 기절 아님 | 공중에서 갑자기 위로 = 밟기 튕김(StompBounce 14 u/s)뿐 |
| 착지 | q 공중 → p 땅. 세기 = q 낙하 속도/20 | |
| 대시 | q 대시 아님 → p 대시 | |
| 대시에 맞음 | q 기절 아님 → p 기절, 그리고 가로로 움직이거나 위로 뜨는 중 | 대시 충돌은 넉백(가로 속도·띄움), 밟힘은 가로 속도 0 이라 구별된다. 가장 가까운 다른 캐릭터를 때린 쪽으로 보고 둘 사이에 충격 |
| 납작 기절 시작 | q 납작 아님 → p 납작 | 대시 기절은 땅에 닿을 때 납작이 된다 |
| 면역 시작 | 면역 틱 0 → 양수 | |
| 사망 | 살아 있음 → 죽음(관전자 제외) | 이 프레임 사망이 있고 생존자가 2 이상 → 1 이하면 '마지막 사망' |
| 위 위험물 예고·꽂힘 | 새 id 가 예고 단계 / 단계가 꽂힘으로 | 창고 화물이 상자가 되면(`AsBox`) 나무 소리 |
| 옆 위험물 예고·지나감 | 새 id 가 예고 / 날아가는 앞 끝이 내 x 를 넘어감 | 듣는 위치는 살아 있는 내 캐릭터, 없으면 카메라 가운데 |
| 순간이동 무시 | 한 프레임에 2.5 넘게 이동 | 라운드 시작 배치 때 착지·점프 소리가 쏟아지지 않게 |

왜 이렇게 했나

- 사건을 '보여 주는 상태'에서 찾으므로 소리·파티클이 화면과 같은 순간에 난다(남은 보간으로 100 ms 늦게, 위험물과 내 캐릭터는 예측 시각에). 서버가 따로 알려 주지 않아도 된다.
- 멈춤·슬로모션은 '화면 표시만'이라는 조건 때문에 세션 시간은 실제 시간(`unscaledDeltaTime`)으로 돌리고, 그림만 과거 프레임을 보여 준다. 그래서 입력 전송·예측·보정 결과가 전혀 바뀌지 않는다. 대가: 멈춘 직후 약 0.04초, 슬로모션 뒤 약 0.45초 동안 화면이 실제보다 늦다(따라잡는 중). 마지막 사망 뒤는 라운드가 끝난 때라 조작에 영향이 없다.
- 슬로모션 동안 결과 화면이 가운데를 가리지 않게, 네트워크 세션의 `State.Screen` 이 결과(Result)이면 따라잡을 때까지 그 직전 화면(진행·관전)으로 되돌려 둔다. 세션이 매 프레임 서버 상태로 화면 값을 다시 정하므로 다음 프레임에 결과로 돌아온다. 미리보기 세션은 화면 값이 자기 상태 기계라 건드리지 않는다.
- 몸 늘어남·찌그러짐은 그림만 바뀐다. 위험물 판정은 서버의 `HitShapes`(그림 모양)라, 늘어난 순간(최대 약 ±40%, 0.2초 안에 돌아옴) 판정 모양과 그림이 조금 달라진다. 크게 하지 않은 이유다.

소리 만들기: `Client/SoundGen/gen_sounds.py`(Python 3 + numpy).

- 효과음: 사인·삼각파·마림바·나무 블록·걸러낸 잡음을 섞고, 몸 소리에는 공통 '출렁임'(음높이 떨림). 마무리에서 앞뒤를 0으로 늘려 걸러(끝이 처음으로 감기지 않게) 코사인 페이드 2 ms·25 ms, **들리는 크기**(A 가중 50 ms 최대 RMS)를 −14 dB(피크 −1 dBFS 아래)로 맞춘 뒤, 종류별 목표 크기와의 차이를 `JuiceLevels.cs` 로 쓴다. 파일 크기를 손으로 맞추던 v1 은 높은 소리가 10~15 dB 튀었다.
- 배경음: 곡마다 선율(`음:박` 표기)과 화음(`C | Am | Dm G`)을 손으로 쓰고, 마디 박 합을 검사한다. 반주는 앞 화음과 가장 가까운 자리바꿈(부드러운 성부 진행), 베이스는 뿌리·5도·옥타브·다음 화음으로 반음 다가가는 음. 박마다 ±4 ms·세기 흔들림, 강박 강세, 창고는 스윙. 악기 줄기(선율·겹침·반주·패드·베이스·킥·타악기·찰찰이)를 따로 쌓아 선율류는 '소리 나는 구간 크기'(100 ms RMS 95번째 백분위)로, 북류는 한 번 칠 때 크기를 맞춘 고정 배수로 섞는다(짧은 딸깍을 100 ms 로 재면 작게 나와 지나치게 커지므로). 악기별 좌우 배치, 좌우 다른 잔향, 2~5 kHz −3 dB(효과음 자리), 9 kHz 위 깎기. 곡 전체는 A 가중 RMS −20 dB 를 목표로 하되 피크가 −2 dBFS 를 넘지 않게 덜 올리고 그 차이를 `JuiceLevels.Bgm` 이 채운다(리미터로 눌러 찌그러뜨리지 않게). 반복 이음매가 없게 끝을 넘는 소리와 잔향은 처음으로 이어 붙인다(원형).

- 측정으로 찾은 '튀는' 원인과 결과: v1 파일 단기 크기 −7.5(옆 예고) ~ −22.6(상자) dB, 실행 중 배수까지 합쳐 기절·예고·카운트가 몸 소리보다 10 dB 안팎 컸다. v2 는 효과음 파일을 모두 −14 dB(피크 막힌 6개는 −16~−22, 표가 채움)로 맞추고 실행 배수로 목표 크기에 맞췄다. 4 kHz 위 에너지는 최대 5.4%(대시), 고드름 14.9% → 0.6%.
- 배경음: 처음 만든 v2 곡에서 이웃 샘플 사이 튐이 최대 1.05(=딸깍)였다. 원인 셋을 찾아 고침: (1) 타악기·뜯는 줄의 0.5~1 ms 순간 시작 → 2 ms 코사인 시작, (2) A 가중이 저음을 작게 재서 곡 전체를 키우다 킥 피크가 리미터에 눌림 → 피크 −2 dBFS 를 넘지 않게 덜 올리고 실행 배수로 채움, (3) 짧은 림 소리 기준으로 타악기 줄기 크기를 맞춰 8·16마디 나무 블록 필인이 0.75 까지 튐 → 한 번 칠 때 크기를 종류별로 맞추고 북 줄기는 고정 배수. 결과 튐 최대 0.22~0.37, 이음매 차이는 이웃 샘플 차이보다 작음(끊김 없음), 좌우 상관 0.81~0.93(스테레오).

확인하지 못한 것(사람이 해 볼 것)

- **소리를 실제로 들어 보기**(v2 도 같다): 이 세션은 소리를 들을 수 없어 파형·스펙트럼 그림과 피크·RMS 값으로만 확인했다. 말랑한 느낌인지, 너무 크거나 거슬리는 소리가 없는지, 배경음이 반복될 때 어색하지 않은지, 효과음과 배경음의 균형(기본 효과음 80·배경음 60)은 들어 보고 판단해야 한다. 고칠 때는 0장 기준대로 `gen_sounds.py` 의 해당 함수 입력이나 `JuiceAudio.BaseVolume` 을 바꾼다.
- 멈춤(0.05초)과 슬로모션이 손맛으로 어떤지, 멈춤이 잦은 난전에서 조작이 늦게 느껴지지 않는지(멈춤 뒤 0.04초 따라잡기)는 직접 해 봐야 안다.
- 엎드림 소리는 대기 화면에서 봇들이 계속 엎드려 많이 난다(남의 소리 0.45배·같은 사람 0.15초 제한). 시끄러우면 남의 엎드림 소리를 빼는 것을 검토.

남은 일·다음 세션에 넘길 것

- UI 개편: 2026-11-10 2차 작업에서 `UiHooks` 로 옮겼다(`JuiceSettings.cs`). 화면 전환 소리는 `JuiceDirector.ScreenEvents` 가 세션 상태로 내므로 `UiHooks.ScreenChanged` 는 쓰지 않는다.
- 캐릭터 모션 세션: `PlayerView` 의 `Body`·`Trail` 자식 이름이나 루트 배율 방식을 바꾸면 `PlayerJuice` 를 맞춘다. 새 착지·찌그러짐 프레임이 생기면 `PlayerJuice` 의 스프링 크기를 줄여 겹치지 않게.
- 맵 레이아웃 세션: 새 위험물 종류가 생기면 `JuiceDirector.HazardLanded` 의 소리·파편 색에 한 줄 추가.
