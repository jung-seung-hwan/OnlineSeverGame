이 처리방침은 Windows 게임 Jelly Survival Party(이하 “게임”)과 게임이 접속하는 온라인 게임 서버(wildmagic.co.kr)가 어떤 정보를 다루는지 설명합니다. 게임 운영자는 Jungsh입니다.

1. 계정과 결제가 없습니다

게임에는 회원 가입, 로그인, 결제, 광고, 채팅 기능이 없습니다. 이메일·전화번호·실명·주소·위치·연락처·사진 같은 정보를 묻거나 수집하지 않습니다.

3. 서버에서 보관하는 정보와 기간

  • 이름·캐릭터·입력은 접속해 있는 동안 서버 메모리에만 있고, 접속을 끊으면 지워집니다. 데이터베이스나 계정에 저장하지 않습니다.
  • 서버는 문제 해결을 위해 실행 기록(로그)을 남깁니다. 로그에는 접속한 IP 주소·포트, 접속 시각, 플레이어 이름, 들어옴·나감·탈락 같은 게임 사건이 적힙니다.
  • 로그는 운영자의 서버 컴퓨터에만 보관하고, 30일이 지나면 지웁니다. 로그를 다른 사람이나 회사에 팔거나 넘기지 않습니다. 법에 따른 요청이 있으면 그 범위 안에서만 제공할 수 있습니다.

4. 내 PC에 저장하는 정보

다음 설정은 내 PC 안(Windows 사용자 설정 영역)에만 저장되고 서버로 보내지 않습니다: 마지막에 쓴 이름, 서버 주소, 언어, 고른 캐릭터, 음량, 화면 흔들림 설정. 게임 실행 기록 파일(Player.log, %USERPROFILE%\AppData\LocalLow\JellySurvivalDev 폴더)도 PC 안에만 남습니다. 게임을 지우면 설정은 함께 지워지고, 실행 기록 폴더는 남으므로 원하면 직접 지우면 됩니다.

5. 제3자 서비스

게임은 Unity 엔진으로 만들었고, Unity 분석(Analytics)·오류 보고(Crash Reporting)·광고·결제 서비스는 꺼져 있습니다. 광고나 분석 도구를 넣지 않았습니다. Microsoft Store에서 받은 경우 다운로드·설치에 관한 정보는 Microsoft가 자기 개인정보 처리방침에 따라 처리합니다.

6. 보안

게임과 서버 사이의 통신은 현재 암호화하지 않습니다. 그래서 이름에 비밀번호나 개인정보를 넣지 마세요. 보내는 정보는 위 표의 게임 정보뿐입니다.

7. 어린이

게임은 나이를 묻지 않고 어린이 정보를 따로 모으지 않습니다. 보호자는 아이가 실명을 이름으로 쓰지 않도록 지도해 주세요.

8. 내 정보 확인·삭제 요청

서버 로그에 남은 내 접속 기록을 확인하거나 지워 달라고 하려면 아래 연락처로 접속한 날짜·시각과 쓴 이름을 알려 주세요. 확인되면 지체 없이 처리합니다. 이름을 바꾸거나 게임을 지우면 PC에 저장된 설정도 바뀌거나 지워집니다.

English

This policy explains what information the Windows game Jelly Survival Party (the “Game”) and the online game server it connects to (wildmagic.co.kr) handle. The Game is operated by Jungsh.

1. No accounts, no payments

The Game has no sign-up, login, payments, ads or chat. It does not ask for or collect your e-mail, phone number, real name, address, location, contacts or photos.

2. What is sent to the server

InformationUsed for
Player name (you type it on the connect screen, up to 32 bytes)Shown to other players in the same room (name tag, ranking)
Chosen character (jelly, jelly bear, pudding)Shown to other players as your character
Controls (move, jump, dash, crouch, emotes) and the host's next-map choiceRunning the game (the server computes movement and results)
Latency check (ping)Showing your ping and smoothing movement
IP address and port (sent automatically by any internet connection)Keeping the connection, troubleshooting logs

Other players only see your name, character, color, movement, emotes and ranking. Your IP address is never shown to other players. Your name is visible to others, so do not use your real name or anything that identifies you.

3. What the server keeps, and for how long

  • Your name, character and inputs live only in the server's memory while you are connected and are gone when you disconnect. There is no database and no account.
  • The server writes a log for troubleshooting. It contains the connecting IP address and port, the time, player names, and game events such as join, leave and elimination.
  • Logs stay only on the operator's server computer and are deleted after 30 days. They are never sold or given to other people or companies, except where the law requires it and only as far as required.

4. What is stored on your PC

These settings are stored only on your PC (your Windows user settings) and are not sent to the server: the last name you used, the server address, language, chosen character, volume and screen-shake setting. The Game's log file (Player.log, in the %USERPROFILE%\AppData\LocalLow\JellySurvivalDev folder) also stays on your PC. Uninstalling the Game removes the settings; the log folder is left behind and you can delete it yourself.

5. Third-party services

The Game is made with the Unity engine; Unity Analytics, Crash Reporting, Ads and In-App Purchasing are turned off. No advertising or analytics tools are included. If you got the Game from the Microsoft Store, Microsoft handles download and installation data under its own privacy statement.

6. Security

Traffic between the Game and the server is currently not encrypted. Do not put passwords or personal information in your player name. Only the game information listed above is sent.

7. Children

The Game does not ask for your age and does not collect information about children in particular. Parents, please make sure children do not use their real names as player names.

8. Seeing or deleting your information

To see or delete your connection records in the server logs, write to the contact below with the date and time you played and the name you used. Once we can identify the records we handle the request without delay. Changing your name or uninstalling the Game changes or removes the settings stored on your PC.

9. Changes

If a new feature changes what information the Game handles, we will update this page and the effective date above.
